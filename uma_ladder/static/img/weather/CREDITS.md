# Weather icon assets

Source: <https://github.com/kachi-dev/uma-tools/tree/master/icons>
(the `utx_ico_weather_NN.png` files).

Mapping mirrors the `Weather` enum in kachi-dev's RaceParameters:

| Filename                     | Weather |
| ---------------------------- | ------- |
| `utx_ico_weather_00.png`     | Sunny   |
| `utx_ico_weather_01.png`     | Cloudy  |
| `utx_ico_weather_02.png`     | Rainy   |
| `utx_ico_weather_03.png`     | Snowy   |

Game art redistributed under the same community-tool posture as
the sibling `statusrank/` and `aptituderank/` directories; see
those CREDITS.md files for the broader context.
